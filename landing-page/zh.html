登录账号

通过 OAuth 浏览器流程添加账号

# 克隆仓库
git clone https://github.com/dong4j/gemini-cli-account-manager.git
cd gemini-cli-account-manager

# 构建二进制文件
go build -o gcam cmd/gcam/main.go

# 安装钩子（可选）
./gcam install

# 添加第一个账号
./gcam pool login

# 开始使用 Gemini CLI
gemini --account gcam
